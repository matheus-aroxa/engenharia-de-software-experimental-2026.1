1. How do we design the checkout flow to minimize abandonment at the critical conversion moment?

The checkout journey uses a "steps progress indicator" to create psychological momentum—users see they're at step 1 of 3, which feels manageable and transparent. We separate concerns into logical sections (Delivery → Shipping → Payment), each with its own card boundary, so the form doesn't feel overwhelming as one monolithic wall of inputs. The order summary sidebar is sticky and always visible, so users never lose confidence in what they're buying or spending. Pre-filled default options (express shipping, saved address) reduce friction—users can submit without re-entering data. The progress bar at top shows Carrinho ✓ completed, reinforcing that the hard work is done.

2. Why present multiple shipping and payment options, and how do we guide users to the most profitable choice?

Offering diverse shipping options (express, standard, economy, pickup) acknowledges different customer priorities—some want speed, others want savings. The default is "Express" (R$ 29,90), positioned first and pre-selected, capturing the premium option for cost-conscious users who don't actively compare. Economy shipping is listed last but marked "Grátis," creating urgency to act before scrolling past it. For payment, we default to card (most common, highest conversion) but prominently display Pix as an alternative—Pix appeals to younger, tech-savvy users and has zero friction (instant confirmation). Boleto serves users without cards or banks that don't support cards. This maximizes conversion across customer segments.

3. How does the sticky order summary function as both a trust signal and a last-chance upsell mechanism?

The sidebar summary stays locked in view, serving three functions: (1) Reassurance – users always see what they're paying and why, eliminating surprise charges at the final step; (2) Trust – visible badges (🔒 100% Seguro, ✓ Satisfação, 📞 24/7) reinforce security at the exact moment users hand over payment data; (3) Upsell – the coupon code field is prominently visible, creating a moment to "find" a discount code, increasing order value if a user enters one. The scrollable item list shows products (phone, watch, earbuds), keeping the order concrete and preventing the abstraction that leads to abandonment. Prices are always visible, so there's no "hidden cost" shock.
