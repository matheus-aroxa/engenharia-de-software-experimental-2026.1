Pergunta 1: Descreva as escolhas visuais da tela (cores, tamanho de elementos, hierarquia visual, layout). Por que você fez essas escolhas?

A página de carrinho utiliza um layout em duas colunas (2fr 1fr) no desktop que reflete a importância relativa: 66% do espaço para visualizar todos os itens e 33% para resumo financeiro. O fundo cinza claro (
#f5f5f5) mantém consistência com a home, enquanto cards de itens em branco (
#ffffff) com borda sutil (
#e0e0e0) criam separação visual clara. Cada item usa grid de 3 colunas (imagem 120px | detalhes | preço+ações) para máxima eficiência de espaço. A imagem do produto em 120x120px é grande o suficiente para reconhecimento rápido sem desperdiçar espaço. O nome do produto em 16px bold e opções em 12px cinza criam hierarquia clara. O controle de quantidade em estilo +/- permite mudanças rápidas, enquanto o preço em 18px laranja (
#ff6b35) chama atenção. Os botões "Remover" e "Salvar para depois" em 14px vermelho e cinza respectivamente indicam ações secundárias. A coluna lateral com resumo usa fundo branco, position:sticky (fica visível ao rolar), e font-sizes crescentes (14px → 18px bold para total em 24px laranja). Cupons, benefícios e botões de ação são organizados verticalmente com gaps consistentes de 12-20px. O layout responsivo reorganiza para coluna única no mobile mantendo todas as funcionalidades.

Pergunta 2: O que aciona a exibição desta tela? Em que momento da jornada do usuário ela aparece?

Esta tela aparece quando o usuário clica no ícone de carrinho no header ou clica em "Ver Carrinho" após adicionar um produto. É o terceiro estágio crítico da jornada de compra: (1) home/descoberta, (2) detalhes de produto, (3) revisão do carrinho (esta tela). O carrinho é acionado após o usuário ter adicionado um ou mais itens durante sua navegação. Se o carrinho está vazio, a tela mostra uma mensagem amigável com botão para "Continuar Comprando". Esta página é essencial pois permite que o usuário revise sua seleção, modifique quantidades, aplique cupons de desconto, visualize o total com cálculo de impostos e frete, e confirme antes do pagamento. É a última oportunidade de revisar antes do checkout, reduzindo arrependimentos pós-compra e aumentando confiança no processo de pagamento.

Pergunta 3: Descreva todas as interações possíveis que o usuário pode ter com esta tela, incluindo todos os botões, links e formas de sair ou avançar.

O usuário tem múltiplas interações disponíveis. Para cada produto no carrinho: pode clicar em botões +/- para aumentar/diminuir quantidade (validado entre 1-10), pode clicar em "Remover" para deletar o item (abre confirmação), pode clicar em "Salvar para depois" para guardar o item em lista. No resumo do pedido, pode digitar um código de cupom e clicar em "Aplicar" (códigos válidos: VITRIO10 para 10%, VITRIO20 para 20%). O botão "Finalizar Compra" leva a modal de confirmação do checkout. O botão "Continuar Comprando" redireciona para produtos. No header, clica em "Conta" (redireciona login), "Favoritos" (redireciona), "Carrinho" (atualiza). A barra de busca permite digitar query e buscar. O breadcrumb permite voltar à home. No footer, múltiplos links para seções. Ao remover item, badge do carrinho atualiza automaticamente. O resumo recalcula em tempo real quando quantidade muda. O cupom, uma vez aplicado, desabilita input e botão evitando aplicação duplicada. Os benefícios (frete grátis, devolução 30 dias, etc) são informativos com ícones. A página é responsiva em mobile reorganizando para coluna única. Ao clicar "Finalizar Compra" com carrinho vazio, mostra validação. Todo clique exibe notificação modal confirmando ação.
