Pergunta 1: Descreva as escolhas visuais da tela (cores, tamanho de elementos, hierarquia visual, layout). Por que você fez essas escolhas?

A página de carrinho usa layout em two-column: 60% à esquerda com itens, 40% à direita com resumo sticky (permanece visível ao scroll). Cores seguem a paleta Vitrio: azul primário para botões de ação (Ir para Pagamento); vermelho/coral para preços e ações destrutivas (Remover); verde para benefícios; cinza para elementos secundários. Cada item é um card branco com sombra, imagem à esquerda (120x120), conteúdo descritivo no centro, quantidade e preço à direita. A quantidade tem selector com − e + para fácil ajuste. O resumo no lado direito é compacto mas informativo: subtotal, cupom, desconto aplicado, frete, total em destaque (18px, bold). A hierarquia visual guia: nome produto > preço grande e em cor de ação > quantidade > CTA checkout em destaque máximo. Escolhi esse layout porque: itens lado a lado com preço facilita comparação; resumo sticky evita scroll desnecessário; cores semânticas indicam ações (vermelho = remover, azul = pagar); design responsivo que colapsa em mobile; cupom e desconto ficam em destaque para upsell de taxa média.

Pergunta 2: O que aciona a exibição desta tela? Em que momento da jornada do usuário ela aparece?

O carrinho é acionado quando o usuário clica no ícone 🛒 no header, após adicionar produtos. É o penúltimo passo antes do pagamento e um ponto crítico: o usuário aqui revisa, pode ajustar quantidades, aplicar cupom, ou abandonar (grande causa de perda de vendas). A página serve como "confirmação" e "portal de revisão": mostra exatamente o que vai pagar, oferece cupom para desconto (reduz abandono), recomenda produtos relacionados (upsell/cross-sell), reforça benefícios (frete grátis, devolução 30 dias) para aumentar confiança. É também oportunidade de capturar cupom válido antes do checkout.

Pergunta 3: Descreva todas as interações possíveis que o usuário pode ter com esta tela, incluindo todos os botões, links e formas de sair ou avançar.

O usuário pode: (1) Aumentar/diminuir quantidade: clicar + e − em cada item para ajustar quantidade (atualiza preço total); (2) Remover item: clicar "Remover" para excluir produto do carrinho (com animação de slide-out); (3) Salvar para depois: clicar "Salvar para depois" para mover item para wishlist; (4) Aplicar cupom: digitar cupom (ex: DESCONTO10, DESCONTO20, VITRIO15) e clicar "Aplicar" para desconto instantâneo; (5) Ir para pagamento: clicar "Ir para Pagamento" para proceder ao checkout; (6) Continuar comprando: clicar "Continuar Comprando" para voltar à home; (7) Adicionar produto relacionado: clicar "Adicionar" em produtos da seção "Quem Comprou Também Viu Isso" para upsell; (8) Navegação geral: clicar logo para home, header para busca/conta; (9) Footer: clicar links de políticas, contato, categorias. A página é totalmente responsiva: em mobile, layout vira single column; resumo passa para sticky bottom; itens aumentam em altura. Todos os preços atualizam em tempo real ao mudar quantidade ou aplicar cupom. Se carrinho fica vazio (tudo removido), substitui grid por "carrinho vazio" com CTA para voltar às compras.
